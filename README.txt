# Rifa de Santiago — PWA

Archivos:
- index.html — aplicación
- manifest.json — configuración PWA
- service-worker.js — funcionamiento offline/caché
- icon-192.png / icon-512.png — iconos

## Publicar en GitHub Pages
1. Crea un repositorio público.
2. Sube los 5 archivos a la raíz.
3. Ve a Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Abre la URL HTTPS que te dé GitHub Pages.

## iPhone
En Safari abre la URL, toca Compartir > Agregar a pantalla de inicio > Agregar.

## Persistencia
Las ventas/folios se guardan con localStorage en el navegador/dispositivo. El respaldo JSON de la app es la copia de seguridad recomendada.
